## 🛠️ Installation

Follow the steps below to run IRIS locally:

```bash
# Clone the repository
git clone https://github.com/arkhen-iris/iris.git

# Navigate to the project directory
cd iris

# Install the dependencies
pip install -r requirements.txt

# Run the application
python app.py
